Read `.team/status.md` and `.team/backlog.md` and report the current state to the human in a
compact board:

- Per active task: id, title, owner, stage, one-line status
- Blocked items with their reason
- Last checkpoint written and any un-archived DONE tasks

If anything is stale, say so (don't silently fix it).
